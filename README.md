# Chiaroscuro

> **Archived**

This repository contains the completed validation work for Chiaroscuro, an
iRacing telemetry viewer built with Rust and Iced. It no longer accepts active
development.

The next iteration is being rebuilt from scratch on
[Codeberg](https://codeberg.org/IshicoR/chiaroscuro). This repository remains
available as an archived record of the validation work.
